# Statut du projet : Quran & Prayer

## Objectif
Création d'une application professionnelle de lecture du Quran et de suivi des heures de prière (offline).

## Stack Technique
* Kotlin
* Jetpack Compose
* Material 3
* MVVM
* Navigation Compose
* Gradle Kotlin DSL

## Architecture
Architecture propre (Core, Data, Domain, Presentation) pour assurer la maintenabilité et l'extensibilité.
